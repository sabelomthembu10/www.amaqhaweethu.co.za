# AmaQhawe ETHU Website

A responsive, modern single-page website redesigned from the supplied AmaQhawe ETHU promotional artwork.

## Files
- `index.html` — page structure/content
- `styles.css` — responsive design and visual system
- `script.js` — mobile navigation, active section highlighting and current year
- `assets/amaqhawe-ethu-flyer.jpeg` — supplied original artwork, retained as a reference asset

## Run locally
Open `index.html` in any modern browser.

No build tools are required.

## Customize
Edit the text and contact details in `index.html`. Main brand colors are defined at the top of `styles.css` as CSS variables.
